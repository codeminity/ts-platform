# Support

## Before opening an issue

Most usage questions are answered in the relevant package's own README — see the package list in [README.md](./README.md).

---

## Found a bug?

Open a [bug report](https://github.com/codeminity/ts-platform/issues/new?template=bug_report.md).

## Want a feature?

Open a [feature request](https://github.com/codeminity/ts-platform/issues/new?template=feature_request.md).

## Have a question?

There's no separate discussion forum yet — open an issue describing what you're trying to do. If it turns out to be a bug or feature request instead, it'll get redirected there.

## Found a security vulnerability?

Don't open a public issue for this — see [SECURITY.md](./SECURITY.md).

---

## Response times

This project is maintained by two people (see [GOVERNANCE.md](./GOVERNANCE.md)) alongside other work — there's no support SLA. Security reports are prioritized (48–72 hours, see [SECURITY.md](./SECURITY.md)); everything else is best-effort.
